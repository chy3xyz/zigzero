# Getting Started

从零开始把 ZigZero 跑起来：安装依赖、写第一个服务、再把它扩成一个有路由、中间件和优雅关闭的 REST API。

按顺序读最省时间；只想先看看效果的话，直接跳到 Quick Start。

- [Installation](./installation.md) — Zig 版本要求、系统依赖（可选数据库库）、把 ZigZero 作为依赖引入
- [Quick Start](./quick-start.md) — 五分钟跑通一个带路由与健康检查的服务器
- [Build Your First Service](./first-service.md) — 完整教程：路由、中间件、参数校验、错误处理、关闭流程

看完之后可以接着读 [How-To Guides](../guides/README.md)（中间件、限流、断路器、SQLx 等）和 [Architecture](../architecture/README.md)（模块参考与设计原则）。
